About this demo

This is a standalone HTML preview of the Job Agent Squad project. The real app has:

  • A Node/Express backend that runs five agents (Hunter, Scout, Rater, Writer, Mailman) against Anthropic / OpenAI / Ollama.
  • Auto-detection of Greenhouse, Lever, Ashby, Workable boards via their public JSON APIs.
  • Gmail + Outlook OAuth for creating email drafts.
  • A Tauri desktop shell wrapping the same web build.

Code lives at examples/job-agent-app/ on branch claude/ai-job-agent-app-GawEn.

To run the real thing locally:

git clone -b claude/ai-job-agent-app-GawEn <repo>
cd claude-flow/examples/job-agent-app
cp .env.example .env
npm install
npm run dev   # http://localhost:8787
